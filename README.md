# Mochi's House

A cosy pixel-art life planner with a pet, rooms, a study planner and more.

- **Use it on the web:** https://mochishouse.app
- **Mac, Windows and Linux app:** download it from [Releases](https://github.com/SmileAnderson/Mochis-house/releases/latest). The app updates itself.
  - Mac: `Mochis-House-mac.dmg`
  - Windows: `Mochis-House-windows-setup.exe`
  - Linux: `Mochis-House-linux.AppImage` (make it runnable with `chmod +x`, then open it; this one updates itself), or `Mochis-House-linux.deb` for Ubuntu and Debian
- **Contact:** hello@mochishouse.app

This repository only holds the finished app. The source code is private.
